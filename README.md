# Student Performance Analytics Dashboard

## Project Overview
This project analyzes fictional student academic data using Python, Pandas, SQL, and Power BI. It explores student marks, attendance, and subject-level performance to identify trends and potential areas for academic support.

## Objectives
- Inspect and clean student performance data.
- Calculate key performance indicators (KPIs).
- Compare average marks across subjects.
- Explore the relationship between attendance and marks.
- Build an interactive Power BI dashboard.
- Use SQL queries to summarize academic performance.

## Tools and Technologies
- Python
- Pandas
- Google Colab
- SQL
- Power BI Desktop

## Repository Structure
- `data/` — Student performance dataset
- `notebooks/` — Python analysis notebook
- `sql/` — SQL analysis queries
- `powerbi/` — Power BI dashboard file
- `screenshots/` — Dashboard screenshot

## Key Questions
1. Which subject has the highest average marks?
2. How does average performance vary between students?
3. Is attendance associated with academic performance?
4. Which students may benefit from additional academic support?

## Dashboard
View the dashboard screenshot in [`screenshots/student_dashboard.png`](screenshots/student_dashboard.png).

Open [`powerbi/student_dashboard.pbix`](powerbi/student_dashboard.pbix) with Power BI Desktop to explore the report.

## How to Use
1. Download the CSV from the `data/` folder.
2. Open the notebook in `notebooks/` using Google Colab.
3. Run the notebook cells in order.
4. Open the `.pbix` file in Power BI Desktop to explore the dashboard.

The SQL queries are available in `sql/analysis_queries.sql`. Import the CSV into a compatible SQL database and create the required table before running them.

## Dataset
The dataset is fictional and contains student identifiers, names, subjects, marks, attendance percentages, and weekly study hours. It is intended for learning and portfolio demonstration, not real academic decisions.

## Limitations
The dataset is small and synthetic. Any relationship between attendance, study hours, and marks is illustrative and does not establish causation or generalize to real students.
